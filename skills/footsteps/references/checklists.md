# 传记写作检查清单

## 田野调查检查清单
- [ ] 已获取传主当时的路线地图或节点描述
- [ ] 已确定至少三个物理环境变化较小的关键“节点”
- [ ] 已在节点现场准备并阅读特定原始文本
- [ ] 已创建平行日记，记录自身与有据推测的传主反应
- [ ] 对地点的描述同时包含历史面貌与现今样貌
- [ ] 已将物理空间细节与传主的内心状态建立联系

## 档案研究检查清单
- [ ] 获取了出版的作品或日记、原始手稿、同期私信
- [ ] 已进行逐段对比，记录的差异为意图性的，而非校订性的
- [ ] 已识别出文本中所有语调突变点
- [ ] 已确认出版文本中哪些内容属“私人加密信息”
- [ ] 对于关键文件缺失，已记录缺失的时空范围并给出合理推测
- [ ] 对“空白期”的处理明确说明了所用资料的性质及局限

## 来源交叉验证检查清单
- [ ] 已对比传主日记（通常简洁，为事实骨架）
- [ ] 已对比同伴日记（通常活泼，为细节血肉）
- [ ] 已对比相关书信（看如何向不同对象转述同一事件）
- [ ] 已对比后期回忆录（识别事后重构的色彩）
- [ ] 评估了每一来源的证人动机、时间距离、与人物关系

## 证据可信度风险评估清单
- [ ] 证人动机：此人是否爱传流言？有无经济利益？社会关系如何？
- [ ] 时间距离：证词是当时记录还是多年后回忆？
- [ ] 删除/修改痕迹：文件是否被编辑、涂改？谁最可能主导修改？
- [ ] 与性格模式的一致性：指控的行为是否符合当事人一贯的行事原则？

## 情感潜台词检测清单
- [ ] 何种普遍的人类困境（如对承诺的恐惧、悲痛、职业选择）在发挥作用？
- [ ] 旅程、创作或信件是否作为一个隐喻性的“朝圣之旅”？
- [ ] 是否有任何奇怪的细节或物品承载着不成比例的情感重量？
- [ ] 私人日记与公开发布版本的差异是否揭示公众形象与私下自我之间的紧张？
- [ ] 是否识别了隐藏的关系驱动力（如“我可能也在追踪一个女人”式的挑战）？

## 信件解读检查清单
- [ ] 是否说明了写信的背景（时间、地点、传主处境）和收信人身份？
- [ ] 对信件中任何“不合常理”的情绪，是否进行了深入分析而非简单接受？
- [ ] 是否区分了针对不同收信人的语气与坦率程度差异？
- [ ] 是否识别了审查环境下的隐语、沉默与审慎措辞？

## 写作质量检查清单
- [ ] 推测性内容已用“可能”、“似乎”等词语明确标记，并与事实区分
- [ ] 对冲突双方的处理是否公平，未仅为一方辩护？
- [ ] 是否将私人关系与智识、政治成长联系起来？
- [ ] 是否呈现了非戏剧化的幸福时刻，而不仅仅是痛苦与挣扎？
- [ ] 是否避免了将传主一生解读为“漫长的自杀”或单一模式？
- [ ] 最终叙述是否在共情理解与批判距离之间取得了平衡？

## 自我审视检查清单
- [ ] 我的解读是否过于简化，将传主归为“病例”？
- [ ] 我是否开始将传主的生活看成一个象征与预兆的系统？
- [ ] 我是否在传主身上过度认同自己？
- [ ] 我能否区分“理解传主的想象世界”与“接受传主的妄想为真实”？
- [ ] 我是否在用传主青年时代的理想标准来审判其中年的选择？
- [ ] 我是否在强行匹配历史类比，而非让传主从时代背景中自然生长？
