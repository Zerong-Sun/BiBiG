# 传记写作工作流

## 阶段一：准备——定义核心问题与收集初始资料

1. **定义核心问题**  
   针对传主生命中的根本矛盾或谜团，提炼一个贯穿始终的问题。例如：“是什么驱使他不断在希望与绝望之间摇摆？”
   将这个问题作为主线，用以筛选和组织所有证据。

2. **收集初始来源**  
   - 传记对象的公开作品（书籍、文章、演讲）
   - 私人文件（日记、书信、笔记草稿）
   - 同期第三方记录（朋友、家人、商业伙伴的信件与回忆录）
   - 官方档案（出生、婚姻、死亡记录、房产文件、审查记录）
   - 照片、肖像、影像资料

3. **制作文件年表**  
   将全部已获取的材料按时间排列，明确标注资料丰富期与空缺期。空白期本身即是重要数据，可能标记了创伤或故意销毁。

## 阶段二：田野调查——足迹追踪

1. **规划路线**  
   依据日记、信件确定传主的实际旅行路径，而不是后代开发的旅游路线。标记至少三个物理环境变化较小的关键“节点”。

2. **感官融入**  
   在关键地点进行感官记录：光线、声音、气味、温度、空间尺度、材料触感。将这一切与传主当日可能体验到的进行对照。

3. **重读原始文本**  
   在传主曾经所处的同一地点，重读其当时创作或书写的文字，触发情感共鸣与顿悟。

4. **记录交汇点**  
   标记“在此地，我推测他们于此刻，思考了这件事”的时刻。随后同时向过去与未来追溯，构建波动而非静止的形象。

5. **平行日记**  
   创建一份日记，同时记录你自身情绪变化（泪水、兴奋、抑郁）与对传主反应的有据推测，前者是理解后者的指示剂。

6. **视角反转**  
   不只要拍摄建筑物的外立面，还要找到传主可能长久凝视的方向（如从窗户向外望），从这个内部视角进行观察与记录，重构其由内向外看到的景象。

## 阶段三：档案研究——文本考古

1. **版本倒溯**  
   对传主反复修改的核心文本，从最终刊行版逐步回溯到杂志初刊、更早版本、最早手稿。对比各版本，识别增删与“文学化”处理。

2. **定位最早版本**  
   最早的手稿通常最接近原始情感真相，后来的修改往往是神话化或掩盖。找到它并提取不变的核心情感陈述。

3. **对比公私文本**  
   将出版的自传性文本与原始日记、私人信件并列比较，识别被删减的私密思考、被替换的语调（如将深情冥想改为轻浮讽刺）以及被填充的无个人色彩的材料。

4. **定位“掩盖痕迹”**  
   - 出版文本中突然的语调转变
   - 用历史背景材料代替个人情感挣扎
   - 删去带有明确宗教或情色意味的思考

5. **解码私人信号**  
   在私人信件中寻找对全书“主线”的证实或揭示。例如传主可能向其信任的朋友透露“书里大量内容都是对某人的公开告白”。

6. **处理文件缺失**  
   当遭遇日记缺页、信件涂抹、档案断裂时：
   - 记录缺失的精确时空范围
   - 追问是谁在何种情境下进行了删除（删除行为本身即是证据）
   - 设法寻找原始手稿或更完整的版本
   - 若无法恢复，则通过同期他人记录侧面填补

## 阶段四：内在旅程分析

1. **诊断外在旅行背后的内在旅程**  
   当传主进行长途旅行、移居或职业变动时，询问其背后的心理驱动。此行为是否发生在重大创伤之后？对象自己如何在私密记录中描述动机？

2. **追踪核心身份符号**  
   密切关注传主名字、笔名、署名方式的变化，这常常是心理重构的直接证据。制作署名演变时间表，记录不同署名在私信、公函、出版物中对不同收件人首次出现的时间与频率。

3. **聆听内在之声**  
   寻找传主碎片化的自我对话（笔记、日记草稿），尤其关注反复出现的主题、意象和呓语。解码这种私密的自我对话，而非忽略它。

4. **绘制情感地图**  
   将传主旅程中的外部事件与其内部、常常隐藏的情感叙事连接起来。识别反复出现的场景或事件，提取贯穿所有版本的不变核心情感陈述。

5. **识别关键决策点**  
   标出传主整个工作方向悬而未决的重大抉择时刻，呈现冲突的双方，不简化评判。

## 阶段五：叙事构建与写作

1. **构建叙事框架**  
   围绕核心问题组织生活素材，寻找传主生命中最根本的矛盾作为主线。采用“十英尺到无限远”的焦距范围——从近距离特写（个人生活）到全景历史（时代背景）。

2. **处理推测性内容**  
   明确区分事实陈述与推测。使用“可能”、“似乎”等语言标记推断，并提供最合理的反对意见或替代解释。推测必须基于多个证据点。

3. **处理次要人物与争议关系**  
   为“被谴责者”提供证据衡平表，分两栏列出支持与反对的所有证据及其来源。将关系置于当时的历史压力与生存威胁下理解，避免以今日道德标准简单评判。

4. **重构家庭内部世界**  
   寻找遗作、附录、前言等容易忽略的隐秘材料（如为儿童写的课程片段、便条）。反向解读传主回忆中对过去时光的理想化描述，识别其中的时间错位。

5. **运用视觉证据**  
   对一系列肖像照片建立时间线，观察发型、服装、饰品、身体特征（皱纹、眼神、姿态）的演变，将细节与生平事件和作品联系。

6. **保持批判距离**  
   避免将传主的人生仅描绘成一连串的灾难或神话。在共情理解与批判审视之间保持平衡。
