# Biography No-Fiction Mandate

**Priority: highest** — overrides all other biography skills on conflict.

## When to Apply

Always. Load this skill **before** `how-to-do-biography`, `biography-vsi`, `footsteps`, or any writing skill.

## Hard Rules

1. **No fabricated details** — Do not invent dialogue, scenes, people, motives, inner thoughts, or biographical facts not present in source material.
2. **Questions open memory, not fiction** — Interview questions must ask the subject to recall; they must not assert unverified events as if the subject lived them.
3. **Era context must be searched** — When a question uses historical or regional context, that context must be retrieved from external sources (e.g. encyclopedia, archive index) for the relevant period and place.
4. **Era context must be labeled** — Mark searched context explicitly, e.g. `【时代背景·已检索·来源：维基百科《…》】`. Never present searched context as the subject's own memory.
5. **No unlabeled "common knowledge"** — Do not smuggle period assumptions into questions without retrieval and attribution.
6. **Silence over invention** — If era research returns nothing reliable, ask a neutral recall question without invented backdrop.

## Expected Outputs

- Writing: prose with no invented facts; uncertainty preserved.
- Questions: each era-referencing question prefixed with a source label; neutral questions when search fails.
- Audit: list of era research items (period, query, summary, source, URL) returned alongside questions.
