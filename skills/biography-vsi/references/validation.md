# 验证规则、决策逻辑与风险警示

## 一、核心决策规则

### 1. 三种伦理立场选择
- **公允评判**：既不神化也不贬低，持续用证据修正初始情感。
- **同情共情**：以“敞开的爱心”进入传主世界，但需设置自我审查节点，避免滑向圣徒传。
- **讽刺批判**：适合揭露伪善，但须有坚实证据，避免沦为单纯的嘲笑。

**决策流程**：写下你对传主的初始预设 → 定期回顾证据如何改变预设 → 根据终版证据调整最终立场。

### 2. 争议性素材纳入标准
引入可能损害传主或他人声誉的材料，必须满足以下至少一项：
- 对理解传主的核心成就或公共角色不可或缺。
- 对理解传主所处时代的机制或文化有普遍启示意义。
- 纠正学界或公众长期以来的错误认知。

若仅为满足好奇心、增加销量或报复，则不应纳入。

### 3. 隐私 vs. 真相处理原则
当隐私披露可能伤害在世亲友时：
- 第一步：评估信息对理解传主的必需程度。
- 第二步：寻求匿名化处理、暗示而非明示等替代呈现方式。
- 第三步：与可能受影响者沟通（在安全范围内），但保留最终叙事责任。
- 终极原则：对真理和人类理解的责任优先于对个体记忆的保护，但不能以此为由肆意伤害。

### 4. 作品与生平关联度判断
- **思想/哲学型传主**：其人生与理念往往同一，可紧密结合。
- **艺术/表演型传主**：区分作品角色与私人自我，追溯制造系统（经纪人、观众等）。
- **政治/从事公共事务型**：聚焦公共行为及其背景网络，私生活仅当其直接影响公共决策或系统运作时纳入。

**风险提示**：切勿在没有直接证据的情况下，把作品情节等同于作者生平（如无据推测丧子创伤导致某悲剧创作）。标示所有解读为推测。

## 二、风险与警告清单

| 风险类型 | 表现 | 缓解措施 |
| :--- | :--- | :--- |
| 神化/圣徒传化 | 只收录正面轶事，忽略缺陷，语气崇拜 | 刻意收集反差细节；启用“乌云”审查：每个章节至少包含一个矛盾或缺陷侧写 |
| 窥私/偷窥化 | 聚焦性、丑闻、隐秘，忽视公共成就 | 回到纳入标准决策规则；问自己“这加深理解还是满足猎奇？” |
| 琐碎化 | 无数无意义的细节堆积，性格不可见 | 用“性格焦点”过滤器删除无关细节；每个细节必须指向中心问题 |
| 扁平化/编年史麻木 | 按时间罗列事件，丧失偶然性与活力 | 引入主题结构或戏剧场景；使用现在时或强聚焦的开端打破线性 |
| 过度心理分析 | 用单一理论（如童年创伤）简化解所有行为 | 让理论服务于素材，而非素材服务于理论；标明心理描写为推测 |
| 冷漠/客观假象 | 假装完全中立，实则隐含判断 | 坦诚自己的立场和局限；向读者显示你的有限视角 |
| 家族审查/授权枷锁 | 作品被过滤、删节，只呈现官方故事 | 预先约定接触未删节档案的权利；考虑引入外部平行视角 |
| 伤害在世者 | 无视亲属感受，披露尚在疼痛中的私隐 | 执行隐私与真相处理原则；在出版前给予知情人基本回应期 |
| 性别与群体刻板化 | 将女性、少数族裔等简化为“突破障碍者”或受害者 | 专项检查清单核实；同时重视其公共成就与个人复杂性 |

## 三、最终质量控制问答（提交前自测）

1. **真实吗？** 所有可核查论断都有可靠来源？推测与事实是否清晰区分？
2. **完整吗？** 主要生命阶段与关系是否均已覆盖？空白处是否诚实说明？
3. **公平吗？** 是否展示了冲突视角和反方证据？是否避免了隐蔽的议程？
4. **生动吗？** 读者能否通过感官细节和具体互动体验到传主的“在场”？是否有僵硬的资料堆砌感？
5. **有意义吗？** 这本传记是否使读者对人性、历史、或某一群体的真实处境产生新的理解？是否有超越“翻案”或“扒粪”的更高追求？
6. **自觉吗？** 叙事是否暗示了自己只是诸多可能版本之一？是否向读者展示了作者的个人印记和局限？

当所有回答均为“是”，方可定稿交付。
