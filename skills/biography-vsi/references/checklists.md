# 传记写作检查清单

## 一、来源与真实性检查

- [ ] 所有关键事实均有至少两个独立来源交叉验证？
- [ ] 每条轶事和引述都标注了原始出处与日期？
- [ ] 区分了“可观察的行动”与“推测的动机”？
- [ ] 识别并标注了来源的潜在偏见（家族、政治、商业等）？
- [ ] 未被证实的假说是否明确标示为推测？
- [ ] 是否存在无法核实的匿名信源？是否已向读者说明其局限性？

## 二、性格与形象呈现检查

- [ ] 传主的形象是否立体，同时包含瑕疵与美德？
- [ ] 是否避免了“尘土使肖像不可见”的琐碎堆积？每个细节都服务主题？
- [ ] 是否通过对话、动作、习惯等具体描写，让读者“看到并听到”传主？
- [ ] 是否容纳了关于同一事件或特质的不同、甚至矛盾的描述？
- [ ] 是否有意收集了“揭示性的琐事”（普鲁塔克式的眼睛表情）？
- [ ] 是否避免了将公共角色等同于传主的全部真实？

## 三、伦理与隐私自问清单

- [ ] 对传主的初始预设（同情/敌视/中立）是否记录并定期审视？
- [ ] 包含的争议性私生活信息是否真正加深了对传主作品或公共角色的理解？
- [ ] 所披露的细节，其价值是否超过对生者可能造成的伤害？
- [ ] 是否存在仅为满足猎奇心而加入的“香艳”材料？
- [ ] 面对传主亲属的期望，是否坚持了忠实于已知事实的底线？
- [ ] 自己的立场（性别、民族、时代、信仰）如何影响了叙述？是否已向读者坦诚？

## 四、结构与叙事检查

- [ ] 所选结构（编年、主题、微观切片等）是否与传主生命特质和史料多寡匹配？
- [ ] 开头第一句或第一段是否确立了核心视角、基调和对既往版本的态度？
- [ ] 叙事是否避免了平铺直叙的“然后”式罗列，而呈现了清晰的因果或主题推进？
- [ ] 证据缺失处的推断是否明确标示？是否避免了虚构传主私密心理？
- [ ] 结尾是否与中心主题形成闭环，同时承认叙事的局限性？

## 五、女性及边缘群体传记专项检查

- [ ] 是否积极挖掘了常规记录中易被忽视的线索（隐藏在男性亲属后的名字、未署名的贡献）？
- [ ] 是否分析了性别、阶级等结构性限制如何影响传主的选择和记录方式？
- [ ] 主体是否被同时视为“体系中的异类”和一个普遍的人来尊重，而非模板化的“突破障碍者”？
- [ ] 是否复原了与传主生活密不可分的“隐形女人”或助手，但赋予了恰如其分的位置？
- [ ] 是否存在将苦难不公正叠加、简化生命为压迫叙事的倾向？

## 六、终审前最终检查

- [ ] 封面、标题、章节名称、索引等副文本是否传递了恰当的信号？
- [ ] 所用语调（幽默、怜悯、批判）是深化了理解，还是仅炫耀技巧或造成伤害？
- [ ] 对于依然在世的相关者，定稿前是否做了最后的沟通与反思？
- [ ] 是否明确承认，所呈现的只是一个特定视角下的临时版本，而非“定本”？
