# 传记研究与写作工作流

## 第一阶段：研究与素材收集

1. **广泛搜集**
   - 系统收集目击者证词、书信、日记、对话记录、社会场合描述、他人回忆、官方文件。
   - 若条件允许，直接与传主或其亲近者互动，记录即时反应和“琐碎细节”。
   - 像弗拉芒画家一样追求精确：记录身体特征、习惯、衣着、吃相等微观信号。

2. **建立“微小细节”档案**
   - 按主题或时间整理卡片/条目，每条注明来源、日期和隐含的性格启示。
   - 囊括不同关系层的视角：家人、朋友、对手、仆人、合作者。
   - 将细节区分为“可观察的行动”与“推测的动机”，后者必须明确标注。

3. **处理对话**
   - 把对话视为展现性格的首要手段。捕捉语气、节奏、反复出现的短语，而不只是精确用词。
   - 事后尽快记录，避免记忆“枯萎”。社交场合若不宜当场记录，应在结束后立即补记。
   - 标注对话发生的情境和自己的在场角色（可能影响传主表达）。

4. **来源评估**
   - 对所有声称“真实”“正宗”的材料保持审慎，尤其是授权传记或传主生前快速出版的版本。
   - 交叉验证关键事件，寻求同时代人的不同记录。
   - 记录每条信息的出处，通过对比揭示偏见（家族保护、文学竞争、政治宣传等）。

## 第二阶段：规划与设计

1. **选择核心隐喻与叙事基调**
   - 决定传记的基本取向：
     * 尸检式：客观事后审查，适用于争议人物或名誉重估。
     * 肖像画式：通过细节捕捉生命感，让传主“如在眼前”。
     * 圣徒传式（需警惕）：理想化的人生原型，易失真。
   - 确立情感距离：同情共情、冷静分析、讽刺幽默还是混合语调？记录初始情感预设，并在过程中修正。

2. **确定结构与时间框架**
   - 根据传主特质和史料多寡选择结构：
     * 严格编年史：按日复一日推进，抵制自我神话化。
     * 主题式：围绕多重自我或核心主题展开，不拘泥于时序。
     * 微缩切片：聚焦关键年份或决定性瞬间，深度挖掘。
     * 群像式：将传主置于群体网络之中，挑战孤立英雄叙事。
   - 选定开头切入：预示核心张力的事件、诞生的诗化记载、反叛宣言或历史大幕拉开的一刻。

3. **设定伦理边界与风险管理**
   - 列出写作可能面临的法律（诽谤、隐私）和声誉风险。
   - 明确区分公共成就与私人生活，评估私生活对理解公共角色的实际价值。
   - 制定处理争议性素材的标准：它能否显著加深对传主或其工作的理解？而非仅为满足猎奇。
   - 与知情人或遗属就可能伤害进行沟通，但坚持忠实于真知的最终责任。

## 第三阶段：写作与塑造

1. **人物塑造策略**
   - 用微小事件揭示性格：一个偶然动作、一句奇怪的话可能比大战役更说明问题。
   - 通过对比配对凸显特质。
   - 分别罗列善行与恶行，呈现立体画像。
   - 区分传主在不同环境下的外在“面具”与其相对稳定的内在性格。

2. **捕捉鲜活的人**
   - 使用鲍斯韦尔式“合作与共”：将自己置于传主场景，记录互动细节和自己的催化作用。
   - 借鉴奥布里式“零碎记录”：混杂理论、道听途说、怪癖与低俗轶事，追求赤裸真实（需在公开发表前适当修剪）。
   - 将材料构建为戏剧场景，展现传主的举止、怪癖和矛盾。

3. **剖析公共表演与私人自我**
   - 绘制传主的“人格面具谱系”，列出所有公共角色与私密身份。
   - 追踪自我塑造的过程：传主如何构建自己的传奇？哪些是“后台”的共谋者？
   - 对艺术家或思想家，寻找声明、行为与作品之间的印证或矛盾，但不做无证据的过度解读。

4. **构筑结尾**
   - 以死亡或生命终章收束主题。描述身体细节、在场者、遗言及最初反响。
   - 使结尾与开端形成主题闭环，但避免虚假的“善终”或生硬医学记录。
   - 承认本版本的暂时性与片面性，向读者示意传记的局限。

## 第四阶段：争议性主体处理

1. **神话层剥离**
   - 识别围绕传主的官方历史、宣传和地下叙事，逐层解剖。
   - 追踪情绪崩溃点或隐藏的个人事件，验证其与官方形象的矛盾。

2. **可验证的控辩档案**
   - 用一手资料支撑每一项重要指责或辩护，避免仅依赖二手论战。
   - 保留矛盾叙述，不强行抹平。当事实无考时，明确写下“我们不知道”。

## 第五阶段：内审与修订

1. **事实核查**
   - 交叉验证所有关键日期、事件和引述。
   - 区分已被证实的陈述与作者的推测，确保后者以“或许”“可能”等标识。

2. **阅读测试**
   - 大声朗读敏感段落，感受是否沦为残忍或偷窥。
   - 邀请一位视角不同的读者，检查是否无意中维护或传播了刻板印象。

3. **附件核查**
   - 封面、标题、目录、索引、图片等副文本是否传递了恰当的信号。
