# Skills

本目录包含 **2** 个传记 Agent Skills。每个技能是一个独立文件夹，至少包含 `SKILL.md`。

## 目录

| 文件夹 | `name` | 来源 | 说明 |
|--------|--------|------|------|
| [how-to-do-biography](how-to-do-biography/) | `how-to-do-biography` | Nigel Hamilton (2008) | 传记实操：从立项到出版 |
| [biography-vsi](biography-vsi/) | `biography-vsi` | Hermione Lee (2009) | 传记理论：定义、规则、评判 |

## 标准结构

```
skill-name/
├── SKILL.md              # 必需：name + description + 入口
├── LICENSE.txt
├── agents/openai.yaml    # Codex UI 元数据
└── references/           # 按需加载
```
